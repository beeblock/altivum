# ALTIVUM Website Design Guide

## Brand Direction

ALTIVUM Cleaning Services should be presented as a premium, luxury service brand — not a common cleaning company.

Core brand message:

> We don’t just clean spaces. We elevate them.

The website must communicate luxury, trust, precision, punctuality, sophistication, attention to detail, and a premium client experience.

---

## Visual Identity

### Colors

| Use | Color |
|---|---|
| Primary Background | #0B0B0B |
| Secondary Background | #111111 |
| Dark Gray | #1C1C1C |
| Primary Text | #FFFFFF |
| Secondary Text | #D9D9D9 |
| Premium Accent | Soft Silver / Champagne |

### Style

- Matte black background
- White and silver typography
- Minimal layout
- Luxury hotel aesthetic
- Editorial spacing
- Large cinematic images
- High contrast
- Clean sections
- Elegant transitions

Avoid bright colors, generic cleaning visuals, overcrowded layouts, cheap icons, and too much text.

---

## Typography

### Headings

Use a luxury serif font such as Cinzel, Playfair Display, Cormorant Garamond, or a Trajan-style font.

### Body Text

Use a clean modern sans-serif font such as Inter, Montserrat, Helvetica Neue, or Lato.

### Typography Style

- Uppercase for brand labels
- Wide letter spacing
- Large headline sizes
- Elegant line height
- Minimal text blocks

## Content Tone

The language should feel premium, confident, calm, elegant, direct, and professional.

Avoid sounding cheap, aggressive, or overly casual.

## Final Brand Experience

The website should make the client feel that ALTIVUM is not simply a cleaning service.

ALTIVUM is a premium experience built around trust, detail, punctuality, presentation, and excellence.

The goal is for the visitor to think:

> This company is different. This company is premium. This company is worth it.
